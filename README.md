# Sistema de Agendamento de Consultas — Especificação de Requisitos

## 1. Visão Geral
Este documento descreve os requisitos do sistema de agendamento de consultas médicas.

## 2. Requisitos Funcionais (RF)
- [ ] RF01: O paciente visualiza os horários disponíveis de cada médico.
- [ ] RF02: O sistema envia confirmação de agendamento por e-mail.
- [ ] RF03: O médico visualiza sua agenda diária e semanal.

## 3. Requisitos Não Funcionais (RNF)
- [ ] RNF01: Busca de horários em menos de 2 segundos.
- [ ] RNF02: Dados protegidos conforme a LGPD.
